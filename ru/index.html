С чего начать

Начните с релиза.

  1. Выберите приложение

    Namaz — времена намазов для Linux. OpenRPM — нативный тест IQ для рабочего стола GNOME.

  2. Установите

    Namaz есть в Flatpak, AppImage и портативном архиве. OpenRPM собирается из исходников через Flatpak Builder. Точные шаги — в README.

  3. Сообщите о проблеме

    Откройте issue: версия приложения, дистрибутив и шаги воспроизведения. Воспроизводимые отчёты помогают быстрее всего.
