Getting started

Start with a release.

  1. Pick an app

    Namaz is for prayer times on Linux. OpenRPM is a native IQ test for the GNOME desktop.

  2. Install it

    Namaz ships as Flatpak, AppImage and a portable archive. OpenRPM is built from source with Flatpak Builder. Each README lists the exact steps.

  3. Report a problem

    Open an issue with the app version, your distribution and the steps to reproduce. Reproducible reports are the fastest way to a fix.
